### ❌ 问题 2：舵机少 1 个，而且有一个是 360° 的

| 买的 | 能不能用 |
|------|---------|
| MG90S **全金属齿轮 180°** ×1 | ✅ 能用，就是标准位置舵机 |
| MG90S 塑料齿 **360°** ×1 | ❌ **不能用**：360° 是「连续旋转舵机」，PWM 控制的是**转速和方向**，不是角度，它只会一直转，停不到指定位置 |
| 数量 | ❌ 只有 2 个，工程需要 **3 个**（窗帘 / 窗户 / 门） |

`servo.c` 发的是 500~2500µs 位置脉宽，期望 0~180° 定位。360° 舵机收到同样脉宽只会转起来。

**必须补买**：`MG90S 全金属齿轮 180°` 或 `SG90 180°` **×2**（一个补数量，一个替掉 360° 那个）。
搜索关键词：`MG90S 舵机 180度 全金属齿轮`（约 ¥6~8/个，两个约 ¥13）。

> 那个 360° 舵机不要扔，以后做小车/风扇摇头还能用。

### ⚠️ 问题 3：雨滴模块是「继电器型」，需确认有没有 AO 模拟输出

截图是「雨水感应控制开关模块 湿度继电器 5V」，板子上有一个**蓝色继电器**。
这类模块通常只有 **DO 数字输出**（+ 继电器触点），**不一定有 AO 模拟输出**。

| 到货后怎么确认 | |
|---|---|
| 看控制板引脚丝印 | 有 `AO`/`A0` → ✅ 直接接 **GPIO2**（但要处理电平，见下）<br>只有 `DO` → ⚠️ 需要我改代码用数字输入（接 **GPIO12**） |

**⚠️ 电平风险（很重要）**：模块标称 5V 供电。如果 AO/DO 输出摆幅是 0~5V，而 ESP32 的 ADC 量程只有 ~3.1V、IO 绝对最大耐压 3.6V —— **直接接有烧 IO 的风险**。

**建议**：
- 先试**用 3.3V 给模块供电**（多数 LM393 模块 3.3V 能工作，只是继电器不吸合 —— 我们本来也不用继电器）。这样 AO/DO 摆幅就是 0~3.3V，安全。
- 如果模块必须 5V 才工作，就在 AO/DO 和 GPIO 之间串一个**分压电阻**（10k + 20k），或者用 3.3V 稳压给传感器部分单独供电。

> 附带好处：这个模块自带继电器，如果你的**窗户是电动推杆/电机**而不是舵机，可以直接用它的继电器输出。

### ⚠️ 问题 4：OLED 排针没焊 + 标题写着 SPI

| 项 | 说明 |
|---|---|
| **不焊排针** | 商品规格写的是「不焊排针」，**排针需要你自己焊上去**（需要电烙铁）。买成品焊好的会省事，但既然买了，焊一下就行 |
| **标题里的 "SPI"** | 标题写「0.96寸OLED显示屏模块SPI」，但规格选的是「**4管脚**」。4 针 = **I2C**（VCC/GND/SCL/SDA），SPI 版是 7 针。所以应该是 I2C，✅ 可用 |
| **到货确认** | 看模块丝印是不是 `GND/VCC/SCL/SDA` 这四针。真是 7 针 SPI 版的话告诉我，需要改驱动（或退换） |
| **地址** | 代码已支持 **0x3C 和 0x3D 自动回退**，两种模块都能用 |

#### 备选路线：多路输出 DC-DC 电源模块

淘宝上常见一种「电源分配模块」，参数类似：

```
输入电压：6-24V          输出电压：5V(六路) + 3.3V(六路)
输出电流：5V@3A(max)     3.3V@1A(max)
特色：带总开关、带 Vout=Vin 直通、KF301 螺丝端子
```

| 优点 | 缺点 / 前提 |
|------|------------|
| ✅ 一次给出 **5V + 3.3V 两条轨**，每轨 6 个输出口，接线极方便 | ⚠️ **它自己不是电源**：需要外接 **6-24V** 输入（12V 适配器），输入源要另买 |
| ✅ **KF301 螺丝端子** + 大电流开关 | ⚠️ **5V 只有 3A**：实际使用约 0.9A（够），但**三个舵机同时堵转 + 喇叭最大音量会到 3.1A，超限** |
| ✅ 3.3V 轨 1A，带传感器 + LED（只要 0.11A）**绰绰有余** | ⚠️ 不能输入 5V（低于 6V 下限） |

**怎么选**：

| 情况 | 建议 |
|------|------|
| 手上**已有 12V 适配器** | ✅ 这个模块很划算，买它。12V 输入至少 **2A**（算下来约 0.9A，留余量买 3A 更好）。**注意别让三个舵机同时憋住** |
| **没有 12V 电源** | ❌ 那就直接买 **AC-DC 的 5V/5A 开关电源**（自带 220V 输入），更省钱省事 |
| 想更保险 | 找 **5V/5A 版本**的同类多路模块，或者 5V 用独立 5A 电源 + 3.3V 借用开发板 |

> 结论：**能用，但记住它需要输入源，且 5V 只有 3A。** 如果单独为它再买一个 12V 适配器，
> 总价和直接买 5V/5A 开关电源差不多，不如买后者省事。

**怎么接**（最省事的方案）：

```text
   ESP32-S3 开发板 ──USB──> 电脑/充电头      （开发板自己走 USB 供电）
   3V3 ──> 4 个 LED 模块的 VCC               （80mA，开发板完全带得动）
   GND ──┬─────────────────────────────┐
         │                             │
   独立 5V/5A 电源 ──┬── 舵机 ×3 (VCC)  │
                     ├── 风扇 (经 MOS)  │
                     └── GND ───────────┘  ★ 共地：两个 GND 必须连一起
```

### 🌧️ 雨滴模块：选型已确认

#### ✅ 推荐买这种：**MH-RD 型「雨滴传感器模块」（LM393 双输出 AO + DO）**

已完成核对，**规格和代码完全对得上，不用改任何代码**：

| 模块规格（卖家页面） | 对本工程的意义 |
|---------------------|---------------|
| 接线表含 **`AO：模拟信号输出`** | ✅ 能接 **GPIO2** 读**湿度百分比**（不只是"下/没下"） |
| `VCC：接电源正极(3-5V)` | ✅ 支持 **3.3V 供电** → AO 摆幅 0~3.3V，**不会烧 ADC** |
| `没水滴 DO 高电平，滴水 DO 低电平` | ✅ 反推出**越湿 AO 电压越低** —— 与 `sensor.c` 的换算方向**逐字一致** |

代码里的换算（[`sensor.c`](../components/BSP/SENSOR/sensor.c) 第 455 行）：

```c
/* RAIN_MV_DRY = 3300mV（干燥），RAIN_MV_WET = 300mV（全湿） */
rain_pct = (RAIN_MV_DRY - mv) * 100.0f / (RAIN_MV_DRY - RAIN_MV_WET);
```

即"干燥 → 电压高 → 0%"、"越湿 → 电压越低 → 百分比越高"，✅ 正确。

#### 接线（只用 3 根线）

```
雨滴模块 VCC ── ESP32 3V3     （★ 用 3.3V，不要用 5V，这样 AO 不会超 ADC 量程）
雨滴模块 GND ── ESP32 GND
雨滴模块 AO  ── ESP32 GPIO2   （ADC1_CH1）
雨滴模块 DO  ── 不接            （AO 已经能读湿度百分比，DO 用不上）
```

> 模块自带的 **DO + 蓝色电位器**用不上（那是给"不用单片机、直接驱动继电器"的场景准备的）。
> 感应板到控制板之间用卖家配的**红色排线**连好即可。

#### 到货后怎么校准

1. 上电，串口调试台敲 `status`，找到 `Rain:` 那一项
2. **干燥状态**读数应接近 0%（3.3V 供电时可能显示 3~7%，因为 AO 略超 ADC 满量程 ~3.1V，**属正常**）
3. 往感应板上**滴几滴水**，`Rain:` 应明显上升；擦掉后回落
4. 想让阈值更贴合实际，用 `cfg rain_pct 30` 改（默认 30% 判定为下雨），改完自动存 NVS

**如果干燥时读数明显偏高**（例如显示 20%+），把 [`sensor.c`](../components/BSP/SENSOR/sensor.c) 里的
`RAIN_MV_DRY` 从 `3300` 改成 `3100`（匹配 ADC 实际满量程）即可。

**搜索关键词**：`雨滴传感器模块 LM393 双输出` 或 `MH-RD 雨滴模块`

---

### 结论一句话

**开发板、AHT20、光敏电阻、ASRPRO 语音模块、风扇、杜邦线都没问题，可以直接开工；**
**补买「5V/5A 电源 + MOS 管模块 + 2 个 180° 舵机」就能全部跑通。**
**LED 已改代码适配（不用买灯带）；雨滴模块先看有没有 AO，没有就花 ¥3 买个 LM393 双输出的。**

## 5. ★ 下单前务必注意的 5 件事

| # | 注意事项 | 后果 |
|---|---------|------|
| 1 | 开发板**必须是 N16R8**（16MB Flash + 8MB **Octal** PSRAM） | 买成 N8R2 等其他型号，`sdkconfig.defaults` 里的 `CONFIG_SPIRAM_MODE_OCT` 不匹配，PSRAM 用不了，后续跑离线语音也不够 |
| 2 | USB 线**必须是数据线**，不能是"只充电"的线 | 插上后电脑完全看不到串口，会让你怀疑板子坏了 |
| 3 | 舵机/灯带**必须配独立电源**，不能用开发板 5V 引脚；**电流按最坏情况选**（本工程 ≈9.8A → 买 5V/10A） | 舵机一动作就拉垮电压 → ESP32 反复复位；电源选小了会一直触发过流保护 |
| 4 | MOS 模块要选 **3.3V 可完全导通**的逻辑电平型号（AO3400 / IRLZ44N） | 常见套装里的 **IRF520 模块 Vgs(th) 偏高**，3.3V 驱动时半导通、发热严重甚至烧管 |
| 5 | I2C 器件（OLED / SHT30 / BH1750）统一**用 3.3V 供电** | 有的模块标称 5V 兼容，但内部上拉会拉到 5V，长期可能损伤 ESP32 的 3.3V IO |
