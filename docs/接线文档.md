# 接线文档 · ESP32-S3 智能家居

> 格式：`模块：器件端 -> 接到哪里`
> 引脚来自 [`components/BSP/board_config.h`](../components/BSP/board_config.h)，改引脚只改那份头文件

## 一、接线清单

```text
OLED 模块：SDA -> GPIO8
OLED 模块：SCL -> GPIO9

温湿度模块 AHT20（0x38）：SDA -> GPIO8
温湿度模块 AHT20（0x38）：SCL -> GPIO9

温湿度模块 SHT30（0x44，备用）：SDA -> GPIO8
温湿度模块 SHT30（0x44，备用）：SCL -> GPIO9

光照模块 BH1750（0x23，可选）：SDA -> GPIO8
光照模块 BH1750（0x23，可选）：SCL -> GPIO9

扩展 IO 模块 PCF8574（0x20，预留）：SDA -> GPIO8
扩展 IO 模块 PCF8574（0x20，预留）：SCL -> GPIO9

I²C 器件（以上全部）：VCC -> 3.3V
I²C 器件（以上全部）：GND -> GND

光敏模块：AO -> GPIO1
光敏模块：VCC -> 3.3V
光敏模块：GND -> GND

雨滴模块：AO -> GPIO2
雨滴模块：DO -> GPIO12
雨滴模块：VCC -> 3.3V
雨滴模块：GND -> GND

五位 AD 键盘：OUT -> GPIO10
五位 AD 键盘：VCC -> 3.3V
五位 AD 键盘：GND -> GND

LED 模块（客厅）：S -> GPIO4
LED 模块（厨房）：S -> GPIO5
LED 模块（卧室）：S -> GPIO6
LED 模块（浴室）：S -> GPIO7
LED 模块 ×4：VCC -> 3.3V
LED 模块 ×4：GND -> GND

舵机（窗帘）：已停用（写死不接，GPIO15 空着不出波形）
舵机（窗户）：信号 -> GPIO16（关位 30°、开位 150°，两头各留余量）
舵机（门）：信号 -> GPIO17（关位 30°、开位 150°，两头各留余量）
舵机 ×2：红 -> 5V
舵机 ×2：棕黑 -> GND

MOS 模块：栅极 -> GPIO18
MOS 模块：电源+ -> 5V
MOS 模块：电源− -> GND
风扇：红 -> 5V
风扇：黑 -> MOS 模块「输出−」

按键 KEY2：一脚 -> GPIO11
按键 KEY2：另一脚 -> GND

INMP441 麦克风：SCK -> GPIO13
INMP441 麦克风：WS -> GPIO39
INMP441 麦克风：SD -> GPIO40
INMP441 麦克风：L/R -> GND
INMP441 麦克风：VDD -> 3.3V
INMP441 麦克风：GND -> GND

板载状态灯：板载 -> GPIO48（v1.0 板为 GPIO38）
```

## 二、电源

```text
12V 适配器（12V / ≥2A）：输出 -> 多路电源模块输入
多路电源模块 5V 轨（3A）：输出 -> 舵机 ×2、风扇
多路电源模块 3.3V 轨（1A）：输出 -> OLED、传感器、LED ×4、麦克风
ESP32-S3 开发板：USB -> 电脑 / 5V 充电头（单独供电）
12V 适配器 GND -> 多路模块 GND -> ESP32 GND（★ 必须拧在一起）
```

## 三、不能接的脚

```text
GPIO26–32 -> 模组内部 Flash，不能接
GPIO33–37 -> Octal PSRAM 专用，接了就随机死机
GPIO19/20 -> USB，不能接
GPIO43/44 -> 串口烧录，不能接
GPIO0/3/45/46 -> 启动 strapping
```
