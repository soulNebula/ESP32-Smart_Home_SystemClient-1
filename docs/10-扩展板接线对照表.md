# 10 · 扩展板接线对照表（照着你手上这块板子的丝印插）

> 依据：`ESP32-S3 GPIO Extension Board`（6 处标注：①数字量IO引脚 ②3.3V输出引脚 ③5V输出引脚 ④DC2.1供电接口 6.5~9V ⑤开发板安装位 ⑥开发板引脚）

## 1. 你这块扩展板上的 6 个标注 = 什么

| 标注 | 是什么 | 怎么用 |
|:----:|--------|--------|
| ① | **数字量 IO 引脚**：左右两排带丝印的插孔 | ★ 所有信号线插这里，**丝印直接写着 IO 号**，不用数排针 |
| ② | **3.3V 输出**：一块 3 行 × 2 列的小排针（左列 `GND`×3，右列 `3V3`×3） | 给 3.3V 器件供电用（OLED/AHT20/光敏/雨滴/LED） |
| ③ | **5V 输出**：同样一块排针（左列 `GND`×3，右列 `5V`×3） | ⚠️ **不要接舵机/风扇/ASRPRO**，见第 2 节 |
| ④ | **DC2.1 供电座，标称 6.5~9V** | ⚠️ **12V 适配器不能插**（超压）；也别和 USB 同时插 |
| ⑤ | ESP32-S3 开发板安装位（板子插在中间） | 开发板 USB 口在中间偏下，仍可直接插 USB |
| ⑥ | ESP32-S3 开发板引脚（开发板自己那排脚的丝印） | 只是给你看针脚顺序，线插 ① 那一排 |

### 左右两排丝印孔（从上到下，实测读数）

| 左排（①的数字量IO，左侧） | 右排（①的数字量IO，右侧） |
|---|---|
| `IO4` `IO5` `IO6` `IO7` `IO15` `IO16` `IO17` `IO18` `IO8` `IO3` `IO46` `IO9` `IO10` `IO11` `IO12` `IO13` `IO14` | `IO1` `IO2` `IO42` `IO41` `IO40` `IO39` `IO38` `IO37` `IO36` `IO35` `IO0` `IO45` `IO48` `IO47` `IO21` `IO20` `IO19` |

> 每一行有**红、黄两个插孔**（同一行的两个孔是同一个信号，任选一个插；不放心可以用万用表通断档量一下两孔是否相通）。
> 本项目要用到的号：左排 **4/5/6/7/8/9/10/11/15/16/17/18**，右排 **1/2/21/47** —— 全都在。

## 2. 三个电源口，哪个能用哪个不能用 ★ 最容易翻车

| 电源 | 能力 | 结论 |
|------|------|------|
| ② **3V3 排** | 来自开发板 3.3V LDO | ✅ **就用它**给 OLED/AHT20/光敏/雨滴/LED×4（合计约 110mA） |
| ③ **5V 排** | 来自 USB 5V 或 DC 座，电流很小 | ❌ **别接舵机/风扇/ASRPRO**：3 个舵机堵转 2.1A，这里给不了，会把开发板拉到复位 |
| ④ **DC 座（6.5~9V）** | 板上降压后供 5V/3.3V | ⚠️ **12V 适配器不能插**（标称上限 9V）<br>⚠️ **插了 DC 就别插 USB**（两路 5V 打架/倒灌）<br>→ **推荐：DC 座空着，开发板走 USB** |
| **独立 5V 模块**（5V@3A + 3.3V@1A） | 外部电源 | ✅ **舵机×3 + 风扇 + ASRPRO 全部走这里**，且它的 **GND 必须接到扩展板 ②/③ 的 `GND`**（共地） |

**三条铁律**：① 会转的/会响的走独立电源 ② 所有 GND 连一起 ③ 不要同时给开发板两路供电。

> ⚠️ 12V 适配器 **只进**多路电源分配模块的输入端，**永远不要插扩展板的 DC 座**。

## 3. 孔位对照总表（★ 照着插）

| 器件 | 器件引脚 | 插到扩展板的孔 | 供电 |
|------|---------|---------------|------|
| **OLED** | SDA | `IO8` | VCC→`3V3`（②排），GND→`GND`（②排） |
| | SCL | `IO9` | ★ VCC 不要接 5V |
| **AHT20** | SDA | `IO8`（与 OLED 并联） | VCC→`3V3`，GND→`GND` |
| | SCL | `IO9`（与 OLED 并联） | |
| **光敏模块** | AO | `IO1`（右排第 1 行） | VCC→`3V3`，GND→`GND`；`DO` 不接 |
| **雨滴模块** | AO | `IO2`（右排第 2 行） | VCC→`3V3`（★别用 5V），GND→`GND`；`DO` 不接 |
| **LED 客厅** | S | `IO4` | VCC→`3V3`，GND→`GND` |
| **LED 厨房** | S | `IO5` | 同上 |
| **LED 卧室** | S | `IO6` | 同上 |
| **LED 浴室** | S | `IO7` | 同上 |
| **舵机 · 窗帘** | 橙（信号） | `IO15` | 红→**独立 5V**，棕→**独立 GND** |
| **舵机 · 窗户** | 橙 | `IO16` | 同上 |
| **舵机 · 门** | 橙 | `IO17` | 同上 |
| **MOS 管模块** | 信号/栅极 | `IO18` | 电源+→独立 5V，电源−→独立 GND |
| **风扇** | 红 (+) | —（直接去独立 5V） | |
| | 黑 (−) | —（接 **MOS 的「输出−」**，不是直接接 GND） | |
| **ASRPRO 语音** | TXD | `IO21`（★ 交叉） | VCC→**独立 5V**，GND→**独立 GND** |
| | RXD | `IO47`（★ 交叉） | 麦克风/喇叭插 ASRPRO 板上 |
| **按键 1**（可选） | 一脚 | `IO10` | 另一脚→`GND`（内部上拉，不用电阻） |
| **按键 2**（可选） | 一脚 | `IO11` | 另一脚→`GND` |
| **INMP441 麦克风**<br>（离线语音 ESP-SR） | **SCK**（位时钟） | **`IO13`**（左排） | VCC→`3V3`（②排，★**不要接 5V**），GND→`GND`（②排） |
| | **WS**（帧同步） | **`IO39`**（右排） | |
| | **SD**（数据） | **`IO40`**（右排） | |
| | **L/R**（声道选择） | **`GND`**（②排） | ★ **单麦必须固定接一端**；悬空 = 左右乱跳 = 无声 |
| | VDD | `3V3`（②排） | ★ 1.8~3.3V 器件，接 5V 会损坏 |
| | GND | `GND`（②排） | 可与 L/R 共用一个 GND 孔 |

> ⚠️ **INMP441 是 I²S，不是 I²C！** 它是**数字音频**麦克风，走
> `SCK`/`WS`/`SD` 三根信号线（I²S 点对点数据流，**没有从机地址**），
> **不能**像 OLED/AHT20 那样挂在 `IO8`(SDA)/`IO9`(SCL) 上 ——
> 插到 I²C 上的表现是"程序不报错、麦克风永远没数据"。
> INMP441 与原有的 **ASRPRO 语音模块是二选一**（menuconfig 里切换），
> 详见 [13-语音模块-ESP-SR.md](13-语音模块-ESP-SR.md)。
> 占用 `IO39~IO42` 会让**内置 JTAG 调试失效**（本工程用 UART 桥烧录，JTAG 本来就没用）。

> 共地只需要 **一根线**：把独立电源模块的 `GND` 接到扩展板 ② 或 ③ 排的任意一个 `GND` 孔。
> I2C 三件套（OLED/AHT20）SDA 都并到 `IO8`、SCL 都并到 `IO9`，靠地址区分不会冲突。

## 4. ⛔ 这些孔**绝对不要插**

| 孔 | 原因 |
|----|------|
| `IO35` `IO36` `IO37` | **N16R8 的 Octal PSRAM 占用**，接外设会 PSRAM 错乱、随机死机 |
| `IO19` `IO20` | USB D- / D+，接了 USB 就认不到 |
| `IO0` `IO3` `IO45` `IO46` | 启动 strapping，上电电平不对会进不了正常启动 |
| `IO48` | 板载 RGB 状态灯（本工程在用） |
| `IO38` | 留给 v1.0 板子的状态灯，别占 |
| `IO4/5/6/7/8/9/1/2/10/11/15/16/17/18/21/47` | 已被本工程功能占用（见第 3 节总表），别重复接 |

> 还剩可以自由用的：`IO12` `IO13` `IO14` `IO39` `IO40` `IO41` `IO42`（以后加传感器）。
>
> ⚠️ `IO13` / `IO39` / `IO40` 已登记给 **INMP441 麦克风**（见第 3 节总表，离线语音方案用）。
> 该方案与 ASRPRO 是二选一，只有打开 `CONFIG_APP_VOICE_SOURCE_ESP_SR` 时才会真正用到这三个脚；
> 用 ASRPRO 时它们仍是空闲的。
> `IO41` / `IO42` 仍完全空闲。

> ⚠️ **DC 座旁边那个写着 `TX/RX` 的小排针，是 UART0（GPIO43/44，烧录/日志口），不要拿来接语音模块** ——
> 语音模块一定要用丝印为 **`IO47`（ESP TX→模块 RXD）** 和 **`IO21`（ESP RX←模块 TXD）** 这两个孔。

| ☐ | 开模块开关，先只接 **1 个舵机**（门） | 橙→`IO17` | `set door 100` 转动，**ESP32 不复位** |

| ☐ | （可选·二选一）接 **INMP441 麦克风** | SCK→`IO13` `WS`→`IO39` `SD`→`IO40` `L/R`→`GND` `VDD`→`3V3` `GND`→`GND` | 串口敲 `mic` → `就绪(采到有效音频) = 是 ★`；再喊「你好小智」+「打开客厅灯」，日志出现 `命令词命中`。详见 [13-语音模块-ESP-SR.md](13-语音模块-ESP-SR.md) |

**上电顺序**：先插 USB → 再开模块总开关。**断电反过来**。
**每加一个器件**都敲一次 `status`，出问题立刻知道是谁。

## 6. 出问题先查这 4 条

1. **LED 关不掉**（一直亮）→ 模块是低电平点亮，把 [`board_config.h`](../components/BSP/board_config.h) 的 `BSP_LED_PLAIN_ACTIVE_LOW` 改成 `1` 重新编译。
2. **I2C 扫不到** → 确认 `IO8`=SDA、`IO9`=SCL 没接反，VCC 接的是 `3V3` 不是 `5V`，换到同行的另一个孔试试。
3. **舵机一动就重启** → 供电不足。确认舵机红线接的是**独立 5V**（不是扩展板 ③ 5V 排），且独立电源 GND 与扩展板 `GND` 相通。
4. **雨滴读数一直很高** → GPIO2 悬空或模块没 AO；先在 `status` 里看 `Rain:`，接好干燥时应接近 0%。
