# 04 · 接线与供电指南

> 配套文档：[03-引脚分配表](03-引脚分配表.md)（哪根线接哪个脚）
> 本文讲的是**怎么接才不出问题** —— 尤其是供电，这是这类项目最容易翻车的地方。

---

## 0. 先记住三句话

1. **舵机、风扇、灯带要独立 5V 供电**，不能从开发板取电。
2. **独立电源的 GND 必须和开发板的 GND 接在一起**（共地），否则 PWM 信号无效、行为完全随机。
3. **上电顺序：先共地，再给外设上电，最后插 USB 给开发板上电。**

违反第 1 条 → 开发板随机重启；违反第 2 条 → 舵机乱抖或不响应；违反第 3 条 → 可能烧 IO。

---

## 1. 供电：为什么不能用开发板的 5V/3V3 引脚

| 器件 | 典型电流 | 堵转/峰值 |
|------|---------|----------|
| SG90 舵机 | 100 ~ 250 mA | **~700 mA** |
| MG996R 舵机 | 500 ~ 900 mA | **~2.5 A** |
| WS2812 灯珠（每颗满亮白） | ~20 mA | **60 mA** |
| 30 颗灯带全白 | ~0.6 A | **1.8 A** |
| 普通 DC 风扇 | 100 ~ 300 mA | 500 mA |

加起来：**3 个舵机 + 4 条灯带 + 风扇，峰值轻松超过 8A。**

而 ESP32-S3-DevKitC-1 上的板载 LDO 只给得出**几百 mA**，USB 口本身也只有 500mA~1A（还要分给开发板自己）。

> 结果就是：舵机一动，3V3 被拉垮 → ESP32 **欠压复位**，表现成"舵机一转单片机就重启"。

### 1.1 先算清楚要多少电流

> ★ **如果你用的是"普通单色 LED 模块"而不是 WS2812 灯带**（即 `BSP_LED_BACKEND_WS2812 = 0`，
> 也就是 [07-元器件采购订单.md](07-元器件采购订单.md) 里那次采购的情况），电流需求会小非常多：
> 4 颗单 LED 一共才 ~80mA，还能直接由开发板 **3V3** 供电 →
> **独立 5V 电源只需承担「3 个舵机 + 风扇」= 最坏 2.6A → 买 5V/5A 即可。**
>
> 下面按 **120 颗 WS2812** 算的是"上限场景"，留作以后升级灯带时的参考。

本工程满载（按 WS2812 灯带）是 **120 颗 WS2812B**（4 路 × 30 颗，见 `BSP_WS2812_LED_NUM_*`）+ **3 个舵机** + **1 个风扇**：

| 负载 | 数量 | 典型电流 | 峰值 / 最坏 |
|------|:----:|---------|------------|
| WS2812B 灯珠（混合颜色） | 120 颗 | 20 mA/颗 → **2.4 A** | — |
| WS2812B 灯珠（**全白满亮**） | 120 颗 | — | 60 mA/颗 → **7.2 A** |
| SG90 / MG90S 舵机 | 3 | 150 mA/个 → 0.45 A | 700 mA/个 → **2.1 A** |
| MG996R 舵机 | 3 | 700 mA/个 → 2.1 A | 2.5 A/个 → **7.5 A** |
| 5V DC 风扇 | 1 | 0.2 A | 0.5 A |
| 12V 4 线风扇 | 1 | 0.3 A | 0.6 A（走 12V，不占 5V 轨） |

**四种场景下的 5V 总需求：**

| 场景 | 5V 总电流 | 建议电源 |
|------|:---------:|---------|
| **① 典型演示**：灯带混合色 + SG90 正常转动 | **≈ 3.1 A** | 5V/5A |
| **② 最坏情况**：灯带全白满亮 + 3 个 SG90 堵转 | **≈ 9.8 A** | **5V/10A** |
| **③ 极端**：灯带全白 + 3 个 MG996R 堵转 | **≈ 15.2 A** | 必须分路，见 §1.3 |
| **④ 默认亮度降到 50% 后的最坏情况** | **≈ 6.2 A** | 5V/10A 绰绰有余 |

> ★ **结论：直接买 5V/10A（50W），¥40~70。** 它覆盖场景 ①②④，接线最简单。
> 买 5V/5A 也能跑，但**必须把灯带亮度压在 60% 以下、不要长时间全白**，否则会触发电源过流保护。

> ⚠️ **代码默认是全白 + 亮度 100%**（`led.c` 的 `led_init` 里 `brightness` 初值 100）。
> 4 路全开正好落在场景②的 7.2A 上。两个选择：
> ① 买 10A 电源；② 把 `led.c` 里默认亮度改小（改成 50 → 最坏电流立刻降到 3.6A）。

### 1.2 推荐供电接线

```
                 ┌───────────────────────────────────┐
                 │   独立 5V / 10A 开关电源 (50W)     │
                 │   ★ 带螺丝端子、过流保护为打嗝模式  │
                 └──────┬────────────────────┬───────┘
                        │ +5V                │ GND
        ┌───────┬───────┼───────┬────────┐   │
        │       │       │       │        │   │
     [舵机×3] [灯带×4] [风扇] [大电容]   │   │
        │       │       │   4700µF+0.1µF  │   │
        └───────┴───────┴───────┴────────┘   │
                                             │
                          ┌──────────────────┴─────────────────┐
                          │  ★ 共地：独立电源 GND 必须接 ESP32 GND │
                          └──────────────────┬─────────────────┘
                                             │
                                      ESP32-S3 GND
                          （开发板自己用 USB 供电最省事）
```

要点：
- **1000µF 电解电容**并在舵机电源轨和**每条灯带**的 5V-GND 之间（尽量靠近负载），吸收舵机启动浪涌。
- 每个舵机的电源脚再并一个 **100nF 陶瓷电容**更好。
- 电源输出端再并一个 **4700µF**，扛住灯带全白的电流突变。
- 大电流走线用 **20~22AWG（0.5~0.75mm²）**，不要用细杜邦线串 3 个舵机。
- **灯带要从两端（或多点）注入 5V**，只从一头供电会导致尾部变暗/偏色。
- 如果只能用面包板：**别用面包板给舵机供电**，触点电阻撑不住，直接焊线或用接线端子。

### 1.3 什么情况需要分路

单电源要到 10A 以上时，线材和端子会变得麻烦。此时**分两路**更实际（两路仍然必须**共地**）：

```
   5V/3A 电源 ────► 舵机 ×3        （峰值 2.1A，留 40% 余量）
   5V/6A 电源 ────► 灯带 ×4 + 风扇  （混合色 2.6A，全白 7.7A → 需限亮度）
        │                 │
        └────────┬────────┘
                 └── 与 ESP32 GND 连在一起 ★
```

什么时候必须分路：
- 用 **MG996R**（3 个堵转就是 7.5A），舵机单独一路
- 想用便宜的小电源凑（两个 ¥20 的电源比一个 ¥60 的 10A 电源好买）
- 12V 风扇场景：12V 电源 + **12V→5V DC-DC 降压模块**给 5V 轨

### 1.4 选电源要看这 5 个参数

| # | 参数 | 怎么选 | 为什么 |
|---|------|--------|--------|
| 1 | **电压** | **5V 固定**；能微调（4.75~5.25V）更好 | 大电流下线路有压降，可调能补偿；**别买 12V 直接接 5V 器件** |
| 2 | **电流** | 按**最坏情况 × 1.2~1.5** 选 | 电源长期满载会烫、寿命短；按典型值选一定不够 |
| 3 | **过流保护类型** | 要**打嗝模式（hiccup / 自恢复）**，**不要锁死型（latch-off）** | 上电瞬间给大电容充电会有浪涌，锁死型会直接保护关机，得手动断电才能恢复 |
| 4 | **输出端子** | 要**螺丝端子**，不要只有 DC 圆头 | 你要接 4~6 路负载，DC 头得自己转接，接触电阻大 |
| 5 | **线材 / 纹波** | 输出线 ≥20AWG，或自己换粗线 | 22AWG 跑 7A 会明显发热、压降大 |

**不要用**：
- ❌ **手机充电器（5V/2A）** —— 电流不够，且多是 USB 口，没螺丝端子
- ❌ **USB-C PD 充电器 + 诱骗器** —— 能出 5V/3A，但要额外买诱骗板，且不适合多路大电流负载
- ❌ **可调实验电源（实验室那台）** —— 调试很好用，但长期跑不合适，且容易误调电压烧器件

### 1.5 上电后怎么验证供电够不够

| 步骤 | 操作 | 合格标准 |
|------|------|---------|
| 1 | 空载量电源输出 | 5.0 ~ 5.2V |
| 2 | 接上全部负载，**灯带全白 + 舵机来回转**，万用表量**负载端的 5V** | **不低于 4.75V** |
| 3 | 摸电源外壳、电源线 | 温热可以，**烫手就是电流不够或线太细** |
| 4 | 看 ESP32 有没有重启 | 舵机转动时**不能重启**；重启 = 5V 被拉垮或没共地 |
| 5 | `status` 看 WiFi RSSI | 掉到 -80dBm 以下且伴随重启，也说明供电不稳 |

> 没有万用表就只能靠"舵机一动就重启"来判断 —— 这也是为什么建议一起买个万用表（¥30~60）。

### 1.6 供电分配方案（按本工程实际器件）

**核心原则：耗电小的逻辑器件走开发板，耗电大的执行器走独立电源。**

| 器件 | 工作电压 | 电流（典型 / 峰值） | **接到哪** | 为什么 |
|------|:--------:|:------------------:|:----------:|--------|
| **ESP32-S3 开发板** | 5V | 250 mA / 500 mA | **USB**（电脑或充电头） | 自带 USB 供电最省事，也方便烧录调试 |
| OLED SSD1306 | 3.3V | 20 mA | 开发板 **3V3** | I2C 器件，用 3.3V 电平和总线一致 |
| AHT20 温湿度 | 3.3V | 1 mA | 开发板 **3V3** | 同上，I2C |
| 光敏电阻模块 | 3.3V | 5 mA | 开发板 **3V3** | 输出进 ADC，3.3V 才不会超量程 |
| 雨滴模块 MH-RD | 3.3V | 5 mA | 开发板 **3V3** | ★ 接 5V 会让 AO 超 ADC 量程（见 §3.3） |
| LED 模块 ×4 | 3.3V | 4×20 = **80 mA** | 开发板 **3V3** | 总共才 80mA，开发板完全带得动 |
| **舵机 ×3** | 5V | 450 mA / **2.1 A** | **独立 5V** | 堵转 700mA/个，远超开发板能力 |
| **风扇** | 5V | 200 mA / 500 mA | **独立 5V**（经 MOS 管） | 启动/堵转电流大 |
| **ASRPRO 语音模块** | 5V | 100 mA / **500 mA** | **独立 5V** | 喇叭功放吃电流，挂开发板会把开发板拉垮 |

#### 一句话分类

| 分类 | 器件 | 合计电流 |
|------|------|:--------:|
| ✅ **只靠开发板 USB 供电就够** | OLED、AHT20、光敏电阻、雨滴模块、LED ×4 | **≈ 110 mA @3V3**（开发板 3V3 稳出 500mA 以上，余量充足） |
| ⚡ **必须独立 5V 电源** | 舵机 ×3、风扇、ASRPRO 语音 | **最坏 ≈ 3.1 A** |

> ★ **判断标准很简单**：**会转的、会响的**（舵机 / 风扇 / 喇叭）都要独立电源；
> **只读数据的**（传感器 / 屏幕 / 小 LED）走开发板。

#### 供电拓扑图

```text
                  ┌──────────────────────────┐
                  │  USB 5V（电脑 / 充电头）  │
                  └────────────┬─────────────┘
                               │ USB-C
                    ┌──────────▼───────────┐
                    │  ESP32-S3 开发板      │
                    │  （自带 3V3 LDO）     │
                    └──┬───────────────────┘
                       │ 3V3 轨  ≈110mA
        ┌──────────────┼──────────────┬────────────┬───────────┐
        │              │              │            │           │
     [OLED]        [AHT20]      [光敏模块]   [雨滴模块]   [LED ×4]
      20mA           1mA           5mA          5mA         80mA
        │              │              │            │           │
        └──────────────┴──────────────┴────────────┴───────────┘
                       │
                    ESP32 GND ──────────┐
                                        │
   ┌────────────────────────────────────┴─────────────────────────┐
   │           独立 5V / 5A 开关电源 (25W)  最坏 ≈ 3.1A             │
   ├─ 舵机 ×3   VCC ── 5V     （红线）                            │
   ├─ 风扇      ── MOS 管 ── 5V / GND                             │
   ├─ ASRPRO    VCC ── 5V     （喇叭功放吃电流）                   │
   └─ GND ──────────────────────────────► 接到 ESP32 GND ★ 共地    │
   └─ [1000µF 电解电容] 并在 5V-GND 之间（抑制舵机浪涌）            │
```

#### ⚠️ 三条铁律

| # | 规则 | 违反后果 |
|---|------|---------|
| 1 | **只转的/响的走独立电源**，不要从开发板 5V 引脚取电 | 舵机一动 → 电压被拉垮 → ESP32 反复复位 |
| 2 | **独立电源 GND 必须接 ESP32 GND（共地）** | PWM / 串口信号没有参考电平 → 舵机乱抖、语音模块收不到数据 |
| 3 | **不要同时用 USB 和外部 5V 给开发板供电** | 两路电源互相灌电流，可能损坏板子 |

#### 常见问题

| 问题 | 答案 |
|------|------|
| 独立电源只买了一个，接哪？ | 接**舵机 + 风扇 + ASRPRO**。这三个才是耗电大户 |
| LED 能不能接独立 5V？ | **不要**，接开发板 **3V3**。接 5V 后 GPIO 的 3.3V 高电平可能驱动不足，而且没必要 |
| ASRPRO 能不能挂开发板 5V 引脚？ | 小音量下通常能工作，但**喇叭一响就可能拉垮 ESP32**。建议走独立 5V |
| 舵机可以先不接独立电源吗？ | 调试单个舵机、不加载时可以从开发板 5V 试一下；**三个一起动必须上独立电源** |
| 传感器能不能用 5V？ | 光敏/雨滴**必须 3.3V**（输出进 ADC，5V 会超量程）；OLED/AHT20 也统一 3.3V |

## 3. 分器件接线

### 3.1 I2C 器件（OLED + SHT30 + BH1750）

三者**并联在同一条 I2C 总线上**：

```
        3V3 ──┬────────┬────────┬────────┐
              │        │        │        │
           [OLED]  [SHT30]  [BH1750]  [4.7kΩ × 2]
           VCC      VCC      VCC          │
              │        │        │      （模块一般已板载，
         GND ─┴────────┴────────┴────   没有才需要加）
              │
   GPIO8 (SDA) ─┬───────┬───────┐
                │       │       │
              OLED    SHT30  BH1750
                SDA     SDA     SDA
   GPIO9 (SCL) ─┬───────┬───────┐
                │       │       │
              OLED    SHT30  BH1750
                SCL     SCL     SCL
```

- **DIN/DOUT 不用接**，I2C 只有 SDA + SCL 两根信号线。
- 模块上的 `ADDR`/`A0`/`A1`/`A2` 引脚悬空即可（保持默认地址）。
- 线不要太长，**20cm 以内**最稳；太长要降速到 100kHz。

### 3.2 光敏电阻（替代 BH1750 时）

光敏电阻本身是个可变电阻，需要**分压**才能被 ADC 读：

```
   3V3
    │
  ┌─┴─┐
  │   │  GL5528 光敏电阻
  │   │  （越亮阻值越小：亮 ~1kΩ，全黑 ~1MΩ）
  └─┬─┘
    ├──────────────► GPIO1 (ADC1_CH0)
    │
  ┌─┴─┐
  │   │  10kΩ 固定电阻
  └─┬─┘
    │
   GND
```

所以：**越亮 → 光敏阻值越小 → 中点电压越高 → ADC 读数越大**。

> 本工程两种光照方案**自动识别**：上电时先探测 I2C 0x23 有没有 BH1750，
> 有就直接读真实 lux；没有就退回 GPIO1 的光敏电阻分压。
> 光敏模式下 `lux` 是**折算的等效值**，阈值需要重新标定（见 `sensor.c` 里的注释）。

### 3.3 雨滴传感器

```
   3V3 ──── 雨滴模块 VCC
   GND ──── 雨滴模块 GND
   GPIO2 ── 雨滴模块 AO   （模拟量，本工程默认用这个）
   GPIO12 ─ 雨滴模块 DO   （数字量，可选；靠模块上的电位器调阈值）
```

- 模块的感应面**不要长期泡水**，会电解腐蚀。装在窗外稍微倾斜，让水能流走。
- ⚠ 不同厂家的模块**输出极性可能相反**：有的是"越湿电压越低"，有的是"越湿电压越高"。
  本工程默认按**越湿电压越低**折算。如果你的模块相反，改 `sensor.c` 里雨滴换算那一行（代码里已用醒目注释标出）。
- 上电后对着感应面哈口气或滴几滴水，看串口调试台 `status` 里 `Rain:` 的百分比有没有变化，就能验证极性。

### 3.4 WS2812 灯带

```
   独立 5V (+) ──┬───────────── 灯带 +5V
                 └─[1000µF]─┐
                            │
   独立 5V (−) ──┬──────────┴── 灯带 GND
                 │
   ESP32 GND ────┘              ★ 共地（必须）
   
   GPIO4 ──[330Ω]────────────── 灯带 DIN
                                 （串电阻抑制反射，短线可省）
```

**几个容易踩的坑：**

| 问题 | 现象 | 解决 |
|------|------|------|
| 数据电平不匹配 | 前几颗亮、后面乱色 / 完全不亮 | WS2812B 在 5V 供电时，数据高电平阈值约 **3.5V**，而 ESP32 输出只有 **3.3V**，处于临界。解决办法：① 数据线串 330Ω（短线通常能work）② 加 74HCT245 电平转换 ③ 把灯带 VCC 用一只 1N4148 二极管降到 ~4.3V，阈值随之降到 ~3.0V |
| 颜色错乱（红绿互换） | 红蓝/红绿对调 | 本工程已按 **GRB** 顺序发送（绝大多数 WS2812B 是这个顺序）。若是 RGB 顺序的灯珠（如 SK6812-RGB），需要改 `ws2812.c` 的字节顺序 |
| 尾部灯珠闪烁/变暗 | 供电不足 | 灯带要从**两端**或**多处**注入 5V，不要只从一头供电 |
| 第一条灯亮但第二条不亮 | 数据方向接反 | 灯带上有箭头，**DIN 是输入**、DOUT 是输出，别接反 |
| 全白时闪烁重启 | 电流不够 | 每颗灯珠满亮 60mA，30 颗就是 1.8A。降亮度或换更大电源 |

> 测试技巧：先用 `set led_living 10`（10% 亮度）验证，再逐步加到 100%，避免一上来就满功率。

### 3.5 舵机

```
   独立 5V (+) ──┬────────── 舵机 红线 (VCC)
                 └─[1000µF]┐
                            │
   独立 5V (−) ──┬──────────┴── 舵机 棕线 (GND)
                 │
   ESP32 GND ────┘              ★ 共地（必须）

   GPIO15 ────────────────────── 舵机 橙线 (信号)  ← 窗帘
   GPIO16 ────────────────────── 舵机 橙线 (信号)  ← 窗户
   GPIO17 ────────────────────── 舵机 橙线 (信号)  ← 门
```

线序记忆：**红 = 正极，棕/黑 = 负极，橙/黄/白 = 信号**。

调试命令（串口调试台）：

```
set curtain 0      → 窗帘合一端
set curtain 100    → 窗帘开另一端
set door 100       → 开门
set door 0         → 关门
```

如果 0 和 100 的位置反了（该开的时候关），有两种改法：
- 硬件：把舵机摇臂拆下来转到另一侧再装上
- 软件：在 `board_config.h` 里把 `BSP_SERVO_MIN_PULSE_US` / `BSP_SERVO_MAX_PULSE_US` 对调

> 舵机不动时保持力矩会**持续发热耗电**。本驱动不会自动松劲（否则 `servo_set_angle()` 会阻塞调用方），
> 需要时可以在业务里显式调 `servo_detach()`。

### 3.6 风扇

**方案 A：普通 2 线 DC 风扇（用 MOS 管做低边开关）**

```
   风扇电源 (+) ──────────── 风扇 (+)
   ─────────────────────────┐
                            │
   风扇 (−) ────┬───────────┘
                │
             ┌──┴──┐
   GPIO18 ─[100Ω]──┤ G   │  N 沟道 MOS（AO3400 / IRF3205 / 成品MOS模块）
                │     │
   GND ─────────┤ S   │
                └──┬──┘
                   │
                  [10kΩ]  ← 栅极下拉，防止上电瞬间误导通
                   │
                  GND
```

- **必须加 10kΩ 栅极下拉**，否则 ESP32 复位期间 MOS 会乱开。
- 风扇若是感性负载，在风扇两端**反并一只肖特基二极管**（如 1N5819）续流，保护 MOS。
- 风扇电源可以是 12V，不一定和舵机同 5V —— 但要**共地**。

**方案 B：4 线 PWM 风扇（推荐，最省事）**

4 线风扇的引脚是：`GND / +12V / TACH(测速) / PWM(调速)`。

```
   12V ──── 风扇 +12V (黄)
   GND ──── 风扇 GND  (黑)
   GPIO18 ─ 风扇 PWM  (蓝)      ← 直接接，不用 MOS
   GPIO14 ─ 风扇 TACH (绿)      ← 可选，测转速
```

- 4 线风扇的 PWM 输入是**内部上拉的开集电极**，直接接 GPIO 即可，**不需要 MOS 管**。
- Intel 规范的 PWM 频率是 **25kHz** —— 正好是本工程用的值，不会有噪声。
- 要启用测速，把 `board_config.h` 里的 `BSP_FAN_TACH_ENABLE` 改成 `1`。

### 3.7 按键

```
   GPIO10 ──┬──[按键]──┐
            │          │
          （内部上拉）  GND
```

- **不需要外接上拉电阻**，代码里已开启内部上拉。
- 按键接在 **GPIO 和 GND 之间**即可，两个脚不分方向。
- 如果按键抖动厉害（便宜按键常见），在按键两端并一个 **100nF 电容**。

本工程的按键映射（`main.c`）：

| 按键 | 动作 | 效果 |
|------|------|------|
| KEY1 | 单击 | 切换客厅灯 |
| KEY1 | 长按 2 秒 | **全部关闭**（一键离家） |
| KEY2 | 单击 | 切换自动模式 开/关 |
| KEY2 | 长按 2 秒 | 切换风扇 开/关 |

### 3.8 语音模块

```
   ESP32 GPIO47 (TX1) ──────► 模块 RXD
   ESP32 GPIO21 (RX1) ◄────── 模块 TXD
   3V3 或 5V ──────────────── 模块 VCC   ← 看模块规格，多数要 5V
   GND ────────────────────── 模块 GND
```

> ⚠ **TX 接 RX，RX 接 TX** —— 交叉接。这是最常见的接线错误，
> 接成 TX-TX 的话模块完全没反应，而且不会报错。

- 波特率 **9600**，8N1（在 `board_config.h` 的 `BSP_VOICE_BAUD`）
- 模块支持的指令词要**烧录进模块自己**（用模块厂商的上位机软件），
  然后模块通过串口把"命令词序号"或"命令词文本"发给 ESP32。
- 序号映射表在 `components/BSP/VOICE/voice.c` 的 `voice_seq[]`，
  **换模块只需要改那张表**，上层业务代码一行都不用动。
- 验证方法：接好后随便让模块发点数据，串口日志里会出现 `voice cmd: xxx`。

## 4. 上电前检查清单

烧录前逐条打勾，能省掉 90% 的返工：

- [ ] 所有外设的 **GND 都连到了 ESP32 的 GND**（共地）
- [ ] 舵机/灯带/风扇用的是**独立电源**，不是开发板的 5V 引脚
- [ ] 独立电源的**电压和器件匹配**（舵机 5V，灯带 5V，4线风扇 12V）
- [ ] WS2812 的 **DIN 和 DOUT 没接反**（顺着灯带上的箭头）
- [ ] 语音模块 **TX/RX 交叉接**
- [ ] 电源**正负极没接反**（接反必烧）
- [ ] MOS 管栅极有 **10kΩ 下拉**
- [ ] 上电顺序：**先共地 → 再外设电源 → 最后 USB**
- [ ] 第一次上电**不要装舵机摇臂**，先确认转动方向对不对再装
- [ ] 第一次点灯带**先设 10% 亮度**，别一上来就满功率

## 6. 常见故障速查

| 现象 | 最可能的原因 | 排查动作 |
|------|------------|---------|
| 舵机一动，ESP32 就重启 | 供电不足（最常见） | 舵机改独立 5V/3A 供电 + 加 1000µF 电容 + 确认共地 |
| 舵机完全不动 | 没共地，或信号线接错 | 万用表量 ESP32 GND 和 5V 电源 GND 是否导通 |
| 舵机抖动/嗡嗡响 | 共地不良或电源纹波大 | 加电容、缩短地线、换粗线 |
| 灯带前几颗亮后面乱色 | 3.3V 数据电平不够 | 串 330Ω 电阻，或加电平转换，或把灯带电压降到 4.3V |
| I2C 扫不到任何设备 | 供电/上拉/线序 | 量模块 VCC 是否有 3.3V；确认 SDA/SCL 没接反；缩短杜邦线 |
| OLED 不亮但 I2C 能扫到 | 地址不对 | 有些模块是 `0x3D`，改 `board_config.h` 的 `BSP_I2C_ADDR_SSD1306` |
| 温度一直是 `--` | 传感器没识别到 | 看 I2C scan 有没有 0x44/0x38；AHT20 的克隆模块可能 CRC 不匹配 |
| WiFi 连不上 | 用了 5GHz，或密码错 | **ESP32-S3 只支持 2.4GHz** |
| MQTT 连上但收不到控制 | topic 里的唯一 ID 不对 | 看串口日志打印的实际 topic；唯一 ID 默认是 **MAC 后 3 字节** |
| 中文显示成方块 | 该字不在 GB2312 字集里 | 换常见同义字；或改 `astra/config/config.h` 的 `mainFont`（行高会变，需重排，见 docs/12） |
| 编译报组件错误 | `sdkconfig` 冲突 | 删掉 `sdkconfig` 重新 `idf.py set-target esp32s3` |

## 7. 安全提醒

- **不要带电插拔**舵机、灯带、传感器。先断电再改线。
- 独立电源的**电流能力要留余量**：算出来的峰值电流 × 1.5 以上。
- 220V 侧的东西（如果有）不要自己碰，用成品适配器。
- 长时间无人看管时，拔掉独立电源。
