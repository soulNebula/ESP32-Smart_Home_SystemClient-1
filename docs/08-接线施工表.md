# 08 · 接线施工表（12V 适配器 + 多路电源模块方案）

> 🔧 **配套一页接线图：[`接线图.svg`](接线图.svg)** —— 用浏览器打开即可看/打印，含电源分配、GPIO 分配、易错点。
> 本文是它的文字详版（更细的逐器件接线表与施工顺序）。
>
> 这份是**照着插线用的**。方案：`12V 适配器 → 多路电源分配模块 → 输出 5V 轨 + 3.3V 轨`，
> 开发板单独走 USB 供电。
> 引脚来源见 [`03-引脚分配表.md`](03-引脚分配表.md) / [`board_config.h`](../components/BSP/board_config.h)；
> 为什么这么分轨见 [`04-接线与供电指南.md`](04-接线与供电指南.md) §1.6。

---

## 0. 动手前：先确认 12V 适配器

| 检查项 | 要求 | 不满足怎么办 |
|--------|------|-------------|
| **输出电压** | 12V（模块支持 6~24V，12V 最合适） | 5V 的不能用（低于模块 6V 下限） |
| **输出电流** | **≥2A**（实际负载约 0.9A，留余量） | 只有 1A 的话也能跑，但别同时开 3 个舵机 |
| **插头规格** | **5.5×2.1mm** 才插得进模块的 DC005 座 | 插不进就用 **KF301 螺丝端子**接，一样可以 |

> 顺手用万用表量一下适配器输出是不是 12V，避免拿错电源。

---

## 1. 电源分轨总表

| 轨 | 由谁提供 | 带什么 | 电流 |
|:--:|---------|--------|:----:|
| **USB 5V** | 电脑 / 充电头 | **ESP32-S3 开发板**（自己用） | 250 mA |
| **3.3V 轨** | 模块 3.3V（1A） | OLED、AHT20、光敏、雨滴、**LED ×4** | **≈ 110 mA** |
| **5V 轨** | 模块 5V（3A） | **舵机 ×3、风扇、ASRPRO** | 0.9 A（极端 3.1A） |
| **12V** | 适配器直出 | 只进模块输入（本项目不再用 12V） | — |

> ★ **三处 GND 必须连在一起**：12V 适配器/模块 GND、ESP32 GND。
> 不共地的话舵机乱抖、语音模块收不到数据。

---

## 2. 逐器件接线表（★ 照着这个插）

### A 组：I2C 总线（3 个器件并联在 GPIO8/GPIO9 上）

| 器件 | 器件引脚 | 接到 | 说明 |
|------|---------|------|------|
| **OLED** | `GND` | 模块 3.3V 轨 **GND** | |
| | `VCC` | 模块 3.3V 轨 **+3.3V** | ★ 不要接 5V |
| | `SCL` | **GPIO9** | |
| | `SDA` | **GPIO8** | |
| **AHT20** | `VCC` | 模块 3.3V 轨 **+3.3V** | |
| | `GND` | 模块 3.3V 轨 **GND** | |
| | `SCL` | **GPIO9** | 与 OLED 并联 |
| | `SDA` | **GPIO8** | 与 OLED 并联 |
| **光敏模块** | `VCC` | 模块 3.3V 轨 **+3.3V** | |
| | `GND` | 模块 3.3V 轨 **GND** | |
| | `AO` | **GPIO1** | 模拟量 |
| | `DO` | **不接** | 用不上（电位器也不用调） |

> I2C 三个器件的 SDA 全部并在 GPIO8、SCL 全部并在 GPIO9，地址不同不会冲突
> （OLED `0x3C`、AHT20 `0x38`、光敏走 ADC 不占地址）。

### B 组：其他 3.3V 器件

| 器件 | 器件引脚 | 接到 | 说明 |
|------|---------|------|------|
| **雨滴模块** | `VCC` | 模块 3.3V 轨 **+3.3V** | ★ 用 3.3V，不要 5V |
| | `GND` | 模块 3.3V 轨 **GND** | |
| | `AO` | **GPIO2** | 模拟量 → 湿度百分比 |
| | `DO` | **不接** | |
| | — | 感应板 ↔ 控制板用**红色排线**连 | 卖家配的那根 |
| **LED 客厅** | `VCC` | 模块 3.3V 轨 **+3.3V** | |
| | `GND` | 模块 3.3V 轨 **GND** | |
| | `S`（信号） | **GPIO4** | |
| **LED 厨房** | `VCC` / `GND` | 同上 | |
| | `S` | **GPIO5** | |
| **LED 卧室** | `VCC` / `GND` | 同上 | |
| | `S` | **GPIO6** | |
| **LED 浴室** | `VCC` / `GND` | 同上 | |
| | `S` | **GPIO7** | |

> ⚠️ LED 模块丝印可能是 `- / + / S` 或 `GND / VCC / S`，**先看清丝印再插**。
> 如果接完发现"关不掉"（一直亮），说明模块是**低电平点亮**，把
> [`board_config.h`](../components/BSP/board_config.h) 里的 `BSP_LED_PLAIN_ACTIVE_LOW` 改成 `1` 重新编译。

### C 组：5V 执行器（★ 全部走独立 5V 轨）

| 器件 | 线色 / 引脚 | 接到 | 说明 |
|------|------------|------|------|
| **舵机 · 窗帘** | 棕/黑 | 模块 5V 轨 **GND** | |
| | 红 | 模块 5V 轨 **+5V** | |
| | 橙/黄（信号） | **GPIO15** | |
| **舵机 · 窗户** | 棕/黑 | 5V 轨 GND | |
| | 红 | 5V 轨 +5V | |
| | 橙/黄 | **GPIO16** | |
| **舵机 · 门** | 棕/黑 | 5V 轨 GND | |
| | 红 | 5V 轨 +5V | |
| | 橙/黄 | **GPIO17** | |
| **风扇** | 红线 (+) | 模块 5V 轨 **+5V** | |
| | 黑线 (−) | **MOS 管模块的「输出−」** | 不是直接接 GND |
| **MOS 管模块** | 信号/栅极 | **GPIO18** | |
| | 电源 + | 模块 5V 轨 **+5V** | |
| | 电源 − / GND | 模块 5V 轨 **GND** | |
| **ASRPRO 语音** | `VCC` | 模块 5V 轨 **+5V** | 喇叭功放吃电流，别挂开发板 |
| | `GND` | 模块 5V 轨 **GND** | |
| | `TXD` | **GPIO21**（ESP32 的 RX） | ★ TX/RX 交叉接 |
| | `RXD` | **GPIO47**（ESP32 的 TX） | |
| | 麦克风 / 喇叭 | 插到 ASRPRO 板上对应插座 | |

### D 组：按键（可选）

| 器件 | 接法 |
|------|------|
| 按键 1 | 一脚 → **GPIO10**，另一脚 → **GND** |
| 按键 2 | 一脚 → **GPIO11**，另一脚 → **GND** |

> 不需要外接上拉电阻，代码已开内部上拉。

### E 组：开发板供电

| 接法 | 说明 |
|------|------|
| 开发板 ──USB──> 电脑 / 5V 充电头 | ✅ **推荐**，方便烧录调试 |
| ⚠️ 不要 **同时**从模块 5V 引到开发板 `5V` 引脚 | 两路电源会互相灌电流 |

## 3. 接线图

```text
   12V 适配器 (≥2A) ──DC005 或 KF301──┐
                                      ▼
                     ┌────────────────────────────────┐
                     │   多路电源分配模块               │
                     │   5V@3A (6路)  3.3V@1A (6路)    │
                     │   带总开关 · KF301 端子          │
                     └──┬──────────────────────┬───────┘
                        │ 5V 轨                │ 3.3V 轨
        ┌───────────────┼──────────────┐       │
        │               │              │       │
    [舵机×3]        [风扇]        [ASRPRO]     │
     红→5V          红→5V          VCC→5V     │
     棕→GND         黑→MOS−        GND→GND    │
     橙→GPIO15/16/17  MOS信号→GPIO18  TXD→GPIO21
                      MOS−→GND        RXD→GPIO47
        │               │              │       │
        └───────────────┴──────────────┴───────┤
                                               │
    ┌──────────────────────────────────────────┴─────────────────┐
    │  3.3V 轨： [OLED] [AHT20] [光敏] [雨滴] [LED×4]              │
    │    SDA→GPIO8  SDA→GPIO8  AO→GPIO1  AO→GPIO2  S→GPIO4/5/6/7   │
    │    SCL→GPIO9  SCL→GPIO9                                      │
    └──────────────────────────────────────────┬─────────────────┘
                                               │
                          ★ 共地 ──────────────┤
                                               │
                          ┌────────────────────┴─────────────────┐
                          │  ESP32-S3 开发板 (+ 扩展底板)         │
                          │  供电：USB 单独一路                   │
                          └──────────────────────────────────────┘
```

## 4. 施工顺序（建议按这个顺序做，每步都能单独验证）

| 步 | 做什么 | 怎么验证 |
|:--:|--------|---------|
| 1 | 只插 **USB**，烧录固件，看串口有日志 | 出现引脚表 + `board init` 清单 |
| 2 | 接 **3.3V 轨** → 先只接 **OLED** | 串口 `I2C scan` 出现 `0x3C`；屏幕显示开机画面 |
| 3 | 并联 **AHT20** | I2C scan 多出 `0x38`；`status` 里温湿度有数值 |
| 4 | 接 **光敏模块**（AO→GPIO1） | 手电筒照/遮住，`status` 里 `lux` 明显变化 |
| 5 | 接 **雨滴模块**（AO→GPIO2） | 滴几滴水，`status` 里 `Rain:` 百分比上升 |
| 6 | 接 **4 个 LED 模块** | `on led_living` 亮；`set led_living 30` 变暗 |
| 7 | 接 **12V 适配器 → 模块**，**先不开开关** | 测模块 5V 输出应为 5.0~5.2V |
| 8 | 开模块开关，先接 **1 个舵机** | `set door 100` 转动，且 **ESP32 不重启** |
| 9 | 接齐 **3 个舵机** | 逐个测试；三个都动时不重启 |
| 10 | 接 **MOS + 风扇** | `set fan 30/60/100` 转速分档 |
| 11 | 接 **ASRPRO** | 说话后日志出现 `voice cmd: xxx` |
| 12 | 全部接齐 | 手机 MQTTX 发 `{"dev":"all","action":"off"}` 全屋归位 |

> **每步只加一个器件**，出问题立刻知道是谁。`board_init()` 的设计就是逐个 try、失败只告警。

## 5. 上电前检查清单

- [ ] 12V 适配器是 **12V**、插头极性正确（内正外负）
- [ ] 模块的 3.3V 轨**只接 3.3V 器件**，5V 轨**只接 5V 器件**，没有接混
- [ ] **所有 GND 连在一起**（模块 GND ↔ ESP32 GND）
- [ ] OLED / AHT20 / 光敏 / 雨滴 的 VCC 都接的是 **3.3V**（不是 5V）
- [ ] 舵机的**橙线（信号）**接的是 GPIO15/16/17，不是接电源
- [ ] ASRPRO 的 **TXD↔GPIO21、RXD↔GPIO47**（交叉接，没接成 TX-TX）
- [ ] MOS 模块的**栅极加了 10kΩ 下拉**到 GND
- [ ] LED 模块丝印确认过（`S` 接 GPIO，不是接电源）
- [ ] 电源**正负极没有接反**
- [ ] 第一次上电**不装舵机摇臂**，先确认转向对不对
- [ ] USB 和模块 5V **没有同时接到开发板**

---

## 6. 上电顺序

```text
上电： ① 插 USB 给开发板  →  ② 开模块总开关（给执行器上电）
断电： ① 关模块总开关      →  ② 拔 USB
```

> 先给开发板上电，是为了让 GPIO 先进入确定状态，避免执行器上电瞬间被误触发。

---

## 7. 第一次上电后怎么确认一切正常

串口调试台（115200 8N1）依次敲：

```
status                    看全部状态
```

逐项对照：

| 应显示 | 说明 |
|--------|------|
| `board init OK` 或只有个别 `[FAIL]` | 缺的配件只影响那一项功能 |
| `I2C scan done, 2 device(s) found` | 0x3C(OLED) + 0x38(AHT20) |
| `温度有效=yes  T:xx.xC H:xx.x%` | AHT20 正常 |
| `L:xx%`（或 lux）随光照变化 | 光敏正常 |
| `Rain:x.x%` 滴水上升 | 雨滴正常 |
| `backend: plain single-colour LED module` | LED 后端正确 |

然后：

```
on led_living            客厅灯亮
set led_living 30        变暗
set door 100 / close door   舵机转动，ESP32 不重启
set fan 50               风扇转
say led_kitchen_on       模拟语音，厨房灯亮
```

全部通过 → **7 条需求全部打通**。
